# College Complaint Portal

A web-based complaint management system that gives students a simple way to submit college complaints and administrators to review and respond to them.

**Live Demo:** https://complaint-portal-txh4.onrender.com

## Features

- Student registration and login
- Students can submit complaints
- Students can view complaint history
- Administrators can manage teachers
- Administrators can review complaints
- PostgreSQL database
